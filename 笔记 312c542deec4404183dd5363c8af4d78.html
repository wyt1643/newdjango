用户界面

用户界面是网页访问者与该页面交互的方式。作为 Web 开发人员，我们的目标是让这些交互对用户来说尽可能愉快，我们可以使用许多方法来做到这一点。

单页应用程序

以前，如果我们想要一个包含多个页面的网站，我们将在 Django 应用程序中使用不同的路由来实现。现在，我们可以只加载一个页面，然后使用 JavaScript 来操作 DOM。这样做的一个主要优点是，我们只需要修改页面中实际更改的部分。例如，如果我们有一个导航栏，它不会根据您当前的页面而更改，那么我们不希望每次切换到页面的新部分时都必须重新呈现该导航栏。

让我们看一个如何在 JavaScript 中模拟页面切换的示例：

<!DOCTYPE html>
<html lang="en">
    <head>
        <title>Single Page</title>
        <style>
            div {
                display: none;
            }
        </style>
        <script src="singlepage.js"></script>
    </head>
    <body>
        <button data-page="page1">Page 1</button>
        <button data-page="page2">Page 2</button>
        <button data-page="page3">Page 3</button>
        <div id="page1">
            <h1>This is page 1</h1>
        </div>
        <div id="page2">
            <h1>This is page 2</h1>
        </div>
        <div id="page3">
            <h1>This is page 3</h1>
        </div>
    </body>
</html>

请注意，在上面的 HTML 中，我们有三个按钮和三个 div。目前，div 只包含一小部分文本，但我们可以想象每个 div 都包含我们网站上一个页面的内容。现在，我们将添加一些 JavaScript，允许我们使用按钮在页面之间切换。

// Shows one page and hides the other two
function showPage(page) {

    // Hide all of the divs:
    document.querySelectorAll('div').forEach(div => {
        div.style.display = 'none';
    });

    // Show the div provided in the argument
    document.querySelector(`#${page}`).style.display = 'block';
}

// Wait for page to loaded:
document.addEventListener('DOMContentLoaded', function() {

    // Select all buttons
    document.querySelectorAll('button').forEach(button => {

        // When a button is clicked, switch to that page
        button.onclick = function() {
            showPage(this.dataset.page);
        }
    })
});

在许多情况下，当我们第一次访问一个网站时，加载每个页面的全部内容是低效的，因此我们需要使用服务器来访问新数据。例如，当您访问一个新闻网站时，如果该网站在您第一次访问该页面时必须加载它可用的每篇文章，那么该网站的加载时间会太长。我们可以使用类似于我们在上一讲中加载货币汇率时使用的策略来避免这个问题。这一次，我们将看看如何使用 Django 从我们的单页应用程序发送和接收信息。为了说明它是如何工作的，让我们看一个简单的 Django 应用程序。它有两种 URL 模式 urls.py ：

urlpatterns = [
    path("", views.index, name="index"),
    path("sections/<int:num>", views.section, name="section")
]

以及 中的 views.py 两条对应路由。请注意， section 路由接受一个整数，然后返回基于该整数的文本字符串作为 HTTP 响应。

from django.http import Http404, HttpResponse
from django.shortcuts import render

# Create your views here.
def index(request):
    return render(request, "singlepage/index.html")

# The texts are much longer in reality, but have
# been shortened here to save space
texts = ["Text 1", "Text 2", "Text 3"]

def section(request, num):
    if 1 <= num <= 3:
        return HttpResponse(texts[num - 1])
    else:
        raise Http404("No such section")

现在，我们创建了一个站点，我们可以从服务器加载新数据，而无需重新加载整个 HTML 页面！

不过，我们网站的一个缺点是 URL 现在信息量较少。在上面的视频中，您会注意到，即使我们从一个部分切换到另一个部分，URL 也保持不变。我们可以使用 JavaScript History API 来解决这个问题。此 API 允许我们将信息推送到浏览器历史记录并手动更新 URL。让我们来看看如何使用这个 API。想象一下，我们有一个与前一个相同的 Django 项目，但这次我们希望更改我们的脚本以使用历史 API：

// When back arrow is clicked, show previous section
window.onpopstate = function(event) {
    console.log(event.state.section);
    showSection(event.state.section);
}

function showSection(section) {
    fetch(`/sections/${section}`)
    .then(response => response.text())
    .then(text => {
        console.log(text);
        document.querySelector('#content').innerHTML = text;
    });

}

document.addEventListener('DOMContentLoaded', function() {
    document.querySelectorAll('button').forEach(button => {
        button.onclick = function() {
            const section = this.dataset.section;

            // Add the current state to the history
            history.pushState({section: section}, "", `section${section}`);
            showSection(section);
        };
    });
});

在上面的函数中 showSection ，我们使用了该 history.pushState 函数。这个函数根据三个参数为我们的浏览历史添加了一个新元素：

  1. 与状态关联的任何数据。
  1. 大多数 Web 浏览器忽略的 title 参数
  1. URL 中应显示的内容

我们在上面的 JavaScript 中所做的另一个更改是设置参数 onpopstate ，该参数指定了当用户单击后退箭头时我们应该做什么。在这种情况下，我们希望在按下按钮时显示上一节。现在，该网站看起来更加用户友好：

滚动

为了更新和访问浏览器历史记录，我们使用了一个重要的 JavaScript 对象，称为窗口。窗口还有其他一些属性，我们可以使用它们来使我们的网站看起来更漂亮：

  • window.innerWidth ：窗口宽度（以像素为单位）

  • window.innerHeight ：窗口高度（以像素为单位）

虽然窗口表示用户当前可见的内容，但文档引用整个网页，该网页通常比窗口大得多，迫使用户上下滚动以查看页面的内容。为了使用我们的滚动，我们可以访问其他变量：

  • window.scrollY ：我们从页面顶部滚动了多少像素

  • document.body.offsetHeight ：整个文档的高度（以像素为单位）。

我们可以使用这些措施来确定用户是否已滚动到页面末尾，使用 比较 window.scrollY + window.innerHeight >= document.body.offsetHeight .例如，当我们到达页面底部时，以下页面会将背景颜色更改为绿色：

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Scroll</title>
    <style>
        body {
            transition: background 0.3s;
        }
    </style>
    <script>
        // Function to generate paragraphs
        function generateContent() {
            const container = document.createElement('div');
            for (let i = 1; i <= 200; i++) {
                const p = document.createElement('p');
                p.textContent = i; // Set paragraph text to the current number
                container.appendChild(p);
            }
            document.body.appendChild(container);
        }

        // Event listener for scrolling
        window.onscroll = () => {
            // Check if we're at the bottom
            if (window.innerHeight + window.scrollY >= document.body.offsetHeight - 1) {
                // Change color to green
                document.querySelector('body').style.background = 'green';
            } else {
                // Change color to white
                document.querySelector('body').style.background = 'white';
            }
        };

        // Generate content when the window loads
        window.onload = generateContent;
    </script>
</head>
<body>
</body>
</html>

无限滚动

更改页面末尾的背景颜色可能不是那么有用，但是如果我们想实现无限滚动，我们可能希望检测我们是否位于页面末尾。例如，如果你在一个社交媒体网站上，你不想一次加载所有帖子，你可能想加载前十个，然后当用户到达底部时，加载下一个十个。让我们看一个可以做到这一点的 Django 应用程序。此应用程序有两条路径 urls.py

urlpatterns = [
path("", views.index, name="index"),
path("posts", views.posts, name="posts")
]

以及两个相应的视图： views.py

import time

from django.http import JsonResponse
from django.shortcuts import render

# Create your views here.
def index(request):
return render(request, "posts/index.html")

def posts(request):

# Get start and end points
 start = int(request.GET.get("start") or 0)
end = int(request.GET.get("end") or (start + 9))

# Generate list of posts
 data = []
for i in range(start, end + 1):
data.append(f"Post #{i}")

# Artificially delay speed of response
 time.sleep(1)

# Return list of posts
 return JsonResponse({
"posts": data
})

请注意，视图 posts 需要两个参数：一个 start 点和一个 end 点。在此视图中，我们创建了自己的 API，可以通过访问 url localhost:8000/posts?start=10&end=15 来测试该 API，它返回以下 JSON：

{
"posts": [
"Post #10",
"Post #11",
"Post #12",
"Post #13",
"Post #14",
"Post #15"
]
}

现在，在网站加载的模板中 index.html ，我们开始时只有正文中的空 div 和一些样式。请注意，我们在开始时加载静态文件，然后引用 static 文件夹中的 JavaScript 文件。

background-color: #77dd11;

}

}
</style><script scr="{% static 'posts/script.js' %}"></script></head><body><div id="posts"></div></body></html>

现在有了 JavaScript，我们将等到用户滚动到页面末尾，然后使用我们的 API 加载更多帖子：

// Start with first postlet counter = 1;

// Load posts 20 at a timeconst quantity = 20;

// When DOM loads, render the first 20 postsdocument.addEventListener('DOMContentLoaded', load);

// If scrolled to bottom, load the next 20 postswindow.onscroll = () => {
if (window.innerHeight + window.scrollY >= document.body.offsetHeight) {
load();
}
};

// Load next set of postsfunction load() {

// Set start and end post numbers, and update counterconst start = counter;
const end = start + quantity - 1;
counter = end + 1;

// Get new posts and add postsfetch(`/posts?start=${start}&end=${end}`)
.then(response => response.json())
.then(data => {
data.posts.forEach(add_post);
})
};

// Add a new post with given contents to DOMfunction add_post(contents) {

// Create new postconst post = document.createElement('div');
post.className = 'post';
post.innerHTML = contents;

// Add post to DOMdocument.querySelector('#posts').append(post);
};

动画

我们可以使我们的网站更有趣的另一种方法是为它们添加一些动画。事实证明，除了提供样式之外，CSS 还使我们能够轻松地为 HTML 元素制作动画。

要在 CSS 中创建动画，我们使用以下格式，其中动画细节可以包括开始和结束样式 （ to 和 from ） 或持续时间中不同阶段的样式（从 0% 到 100% ）。例如：

@keyframes animation_name {
from {
/* Some styling for the start */}

to {
/* Some styling for the end */}
}

or:

@keyframes animation_name {
0% {
/* Some styling for the start */}

75% {
/* Some styling after 3/4 of animation */}

100% {
/* Some styling for the end */}
}

然后，要将动画应用于元素，我们包括 animation-name 、 animation-duration （以秒为单位） 和 animation-fill-mode （通常 forwards 以 为单位）。例如，下面是一个页面，当我们第一次进入页面时，标题会增长：

<!DOCTYPE html>
<html lang="en"><head><title>Animate</title><style>@keyframes grow {
from {
font-size: 20px;
}
to {
font-size: 100px;
}
}

h1 {
animation-name: grow;
animation-duration: 2s;
animation-fill-mode: forwards;
}
</style></head><body><h1>Welcome!</h1></body></html>

我们可以做的不仅仅是操纵大小：下面的例子显示了如何通过更改几行来更改标题的位置：

<!DOCTYPE html>
<html lang="en"><head><title>Animate</title><style>@keyframes move {
from {
left: 0%;
}
to {
left: 50%;
}
}

h1 {
position: relative;
animation-name: move;
animation-duration: 2s;
animation-fill-mode: forwards;
}
</style></head><body><h1>Welcome!</h1></body></html>

现在，让我们也看看设置一些中间 CSS 属性。我们可以在动画的任意百分比处指定样式。在下面的示例中，我们将通过仅更改上方的动画来将标题从左向右移动，然后从左向左移动

@keyframes move {
0% {
left: 0%;
}
50% {
left: 50%;
}
100% {
left: 0%;
}
}

如果我们想多次重复一个动画，我们可以将 animation-iteration-count 更改为大于 1 的数字（甚至 infinite 用于无休止的动画）。我们可以设置许多动画属性来更改动画的不同方面。

除了 CSS，我们还可以使用 JavaScript 来进一步控制我们的动画。让我们使用移动标题示例（无限重复）来展示如何创建启动和停止动画的按钮。假设我们已经有了动画、按钮和标题，我们可以添加以下脚本来启动和暂停动画：

document.addEventListener('DOMContentLoaded', function() {

// Find headingconst h1 = document.querySelector('h1');

// Pause Animation by defaulth1.style.animationPlayState = 'paused';

// Wait for button to be clickeddocument.querySelector('button').onclick = () => {

// If animation is currently paused, begin playing itif (h1.style.animationPlayState == 'paused') {
h1.style.animationPlayState = 'running';
}

// Otherwise, pause the animationelse {
h1.style.animationPlayState = 'paused';
}
}

})

现在，让我们看看如何将我们的动画新知识应用到我们之前制作的帖子页面中。具体来说，假设我们希望能够在阅读完帖子后隐藏帖子。让我们想象一个与我们刚刚创建的 Django 项目相同的项目，但 HTML 和 JavaScript 略有不同。我们将进行的第一个更改是对 add_post 功能，这次还在帖子的右侧添加了一个按钮：

// Add a new post with given contents to DOMfunction add_post(contents) {

// Create new postconst post = document.createElement('div');
post.className = 'post';
post.innerHTML = `${contents} <button class="hide">Hide</button>`;

// Add post to DOMdocument.querySelector('#posts').append(post);
};

现在，我们将努力在单击 hide 按钮时隐藏帖子。为此，我们将添加一个事件侦听器，每当用户单击页面上的任意位置时，就会触发该侦听器。然后，我们编写一个函数，将 event 作为参数，这很有用，因为我们可以使用该 event.target 属性来访问单击的内容。我们还可以使用该 parentElement 类来查找 DOM 中给定元素的父元素。

// If hide button is clicked, delete the postdocument.addEventListener('click', event => {

// Find what was clicked onconst element = event.target;

// Check if the user clicked on a hide buttonif (element.className === 'hide') {
element.parentElement.remove()
}

});

我们现在可以看到我们已经实现了隐藏按钮，但它看起来并不像它可能的那样好。也许我们想在删除帖子之前让帖子淡出并缩小。为此，我们将首先创建一个 CSS 动画。下面的动画将花费 75% 的时间 opacity 从 1 更改为 0，这实际上会使帖子慢慢淡出。然后，它将剩余时间用于将其 height 所有与属性相关的属性移动到 0，从而有效地将帖子缩小为零。

@keyframes hide {
0% {
opacity: 1;
height: 100%;
line-height: 100%;
padding: 20px;
margin-bottom: 10px;
}
75% {
opacity: 0;
height: 100%;
line-height: 100%;
padding: 20px;
margin-bottom: 10px;
}
100% {
opacity: 0;
height: 0px;
line-height: 0px;
padding: 0px;
margin-bottom: 0px;
}
}

接下来，我们将这个动画添加到我们帖子的 CSS 中。请注意，我们最初将 animation-play-state 设置为 paused ，这意味着默认情况下不会隐藏帖子。

.post {
background-color: #77dd11;
padding: 20px;
margin-bottom: 10px;
animation-name: hide;
animation-duration: 2s;
animation-fill-mode: forwards;
animation-play-state: paused;
}

最后，我们希望能够在单击 hide 按钮后启动动画，然后删除帖子。我们可以通过从上面编辑我们的 JavaScript 来做到这一点：

// If hide button is clicked, delete the postdocument.addEventListener('click', event => {

// Find what was clicked onconst element = event.target;

// Check if the user clicked on a hide buttonif (element.className === 'hide') {
element.parentElement.style.animationPlayState = 'running';
element.parentElement.addEventListener('animationend', () => {
element.parentElement.remove();
});
}

});

正如你在上面看到的，隐藏功能现在看起来好多了！

反应

在这一点上，你可以想象一个更复杂的网站需要多少 JavaScript 代码。我们可以通过使用 JavaScript 框架来减少我们实际需要编写的代码量，就像我们使用 Bootstrap 作为 CSS 框架来减少我们实际必须编写的 CSS 数量一样。最流行的 JavaScript 框架之一是一个名为 React 的库。

到目前为止，在本课程中，我们一直在使用命令式编程方法，即为计算机提供一组要执行的语句。例如，要更新 HTML 页面中的计数器，我们可能有如下所示的代码：

视图：

<h1>0</h1>

逻辑：

let num = parseInt(document.querySelector("h1").innerHTML);
num += 1;
document.querySelector("h1").innerHTML = num;

React 允许我们使用声明式编程，这将允许我们简单地编写代码来解释我们希望显示的内容，而不必担心我们如何显示它。在 React 中，计数器可能看起来更像这样：

视图：

<h1>{num}</h1>

逻辑：

num += 1;

React 框架是围绕组件的概念构建的，每个组件都可以有一个底层状态。组件是您可以在网页上看到的东西，例如帖子或导航栏，状态是与该组件关联的一组变量。React 的美妙之处在于，当状态发生变化时，React 会自动相应地更改 DOM。

使用 React 的方法有很多种（包括 Facebook 发布的流行的 create-react-app 命令），但今天我们将专注于直接在 HTML 文件中开始。为此，我们必须导入三个 JavaScript 包：

  • React ：定义组件及其行为

  • ReactDOM ：获取 React 组件并将它们插入到 DOM 中

  • Babel ：将 JSX（我们将在 React 中编写的语言）翻译成我们的浏览器可以解释的纯 JavaScript。JSX 与 JavaScript 非常相似，但具有一些附加功能，包括在我们的代码中表示 HTML 的能力。

让我们深入研究并创建我们的第一个 React 应用程序！

</script></body></html>

由于这是我们的第一个 React 应用，让我们详细了解一下这段代码的每个部分在做什么：

  • 在标题上方的三行中，我们导入了最新版本的 React、ReactDOM 和 Babel。

  • 在正文中，我们包含一个带有 id 的 app . div 我们几乎总是想把它留空，并在下面的反应代码中填写它。

  • 我们包含一个 script 标签，其中指定 type="text/babel" .这向浏览器发出信号，表明需要使用 Babel 翻译以下脚本。

  • 接下来，我们创建一个名为 App .React 中的组件可以用 JavaScript 函数表示。

  • 我们的组件返回我们想要渲染给 DOM 的内容。在这种情况下，我们只需返回 <div>Hello!</div> .

  • 脚本的最后一行使用该函数，该 ReactDOM.render 函数采用两个参数：

    1. 要呈现的组件
    1. DOM 中的一个元素，组件应该在其中呈现

React 的一个有用特性是能够在其他组件中渲染组件。为了演示这一点，让我们创建另一个组件，称为 Hello ：

function Hello(props) {
    return (
        <h1>Hello</h1>
    );
}

现在，让我们在组件内部渲染三个 Hello App 组件：

function App() {
    return (
        <div>
            <Hello />
            <Hello />
            <Hello />
        </div>
    );
}

这给了我们一个页面，如下所示：

到目前为止，这些组件并不是那么有趣，因为它们都完全相同。我们可以通过向这些组件添加额外的属性（React 术语中的 props）来使它们更加灵活。例如，假设我们希望向三个不同的人打招呼。我们可以在类似于 HTML 属性的方法中提供这些人的名字：

function App() {
    return (
        <div>
            <Hello name="Harry" />
            <Hello name="Ron" />
            <Hello name="Hermione" />
        </div>
    );
}

然后，我们可以使用 props.PROP_NAME .然后，我们可以使用大括号将其插入到 JSX 中：

function Hello(props) {
    return (
        <h1>Hello, {props.name}!</h1>
    );
}

现在，我们的页面显示了这三个名字！

现在，让我们看看如何使用 React 重新实现我们第一次使用 JavaScript 时构建的计数器页面。我们的整体结构将保持不变，但在组件 App 内部，我们将使用 React 的 useState 钩子为我们的组件添加状态。参数 to useState 是状态的初始值，我们将它设置为 0 。该函数返回一个表示状态的变量和一个允许我们更新状态的函数。

const [count, setCount] = React.useState(0);

现在，我们可以处理函数将呈现的内容，我们将指定标题和按钮。我们还将添加一个事件侦听器，用于单击按钮时，React 使用以下 onClick 属性进行处理：

return (
    <div>
        <h1>{count}</h1>
        <button onClick={updateCount}>Count</button>
    </div>
);

最后，让我们定义 updateCount 函数。为此，我们将使用该 setCount 函数，该函数可以将状态的新值作为参数。

function updateCount() {
    setCount(count + 1);
}

现在我们有一个正常运行的柜台站点！

现在我们已经对 React 框架有了一定的了解，让我们使用我们学到的知识来构建一个类似游戏的网站，用户将在其中解决附加问题。首先，我们将创建一个新文件，其设置与其他 React 页面相同。要开始构建此应用程序，让我们考虑一下我们可能希望在状态中跟踪的内容。我们应该包括我们认为在用户访问我们的页面时可能会更改的任何内容。我们的状态可能包括：

  • num1 ：要添加的第一个数字

  • num2 ：要添加的第二个数字

  • response ：用户输入的内容

  • score ：用户正确回答了多少个问题。

现在，我们的状态可以是一个包含所有这些信息的 JavaScript 对象：

const [state, setState] = React.useState({
    num1: 1,
    num2: 1,
    response: "",
    score: 0
});

现在，使用状态中的值，我们可以呈现一个基本的用户界面。

return (
    <div>
        <div>{state.num1} + {state.num2}</div>
        <input value={state.response} />
        <div>Score: {state.score}</div>
    </div>
);

现在，网站的基本布局如下所示：

此时，用户无法在输入框中键入任何内容，因为它的值是固定的，因为 state.response 当前是空字符串。为了解决这个问题，让我们向 input 元素添加一个 onChange 属性，并将其设置为等于一个名为 updateResponse

onChange={updateResponse}

现在，我们必须定义函数，该函数接受触发函数 updateResposne 的事件，并将 response 设置为输入的当前值。此函数允许用户键入，并存储已键入的任何内容 state 。

function updateResponse(event) {
    setState({
        ...state,
        response: event.target.value
    });
}

现在，让我们添加用户提交问题的功能。我们将首先添加另一个事件侦听器，并将其链接到我们接下来要编写的函数：

onKeyPress={inputKeyPress}

现在，我们将定义函数 inputKeyPress 。在这个函数中，我们将首先检查该 Enter 键是否被按下，然后检查答案是否正确。当用户正确时，我们希望将分数提高 1，为下一个问题选择随机数，并清除响应。如果答案不正确，我们希望将分数降低 1 并清除响应。

function inputKeyPress(event) {
    if (event.key === "Enter") {
        const answer = parseInt(state.response);
        if (answer === state.num1 + state.num2) {
            // User got question right
            setState({
                ...state,
                score: state.score + 1,
                response: "",
                num1: Math.ceil(Math.random() * 10),
                num2: Math.ceil(Math.random() * 10)
            });
        } else {
            // User got question wrong
            setState({
                ...state,
                score: state.score - 1,
                response: ""
            })
        }
    }
}

#app {

if (state.score === 10) {
